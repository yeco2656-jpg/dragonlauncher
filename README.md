# 龙裔启动器 DragonLauncher

朋友自制的 Minecraft Java 版启动器，这里是它的下载站与版本归档。

- 在线网站：<https://yeco2656-jpg.github.io/dragonlauncher/>
- 主推版本：**v0.4.0 主题库版**（`downloads/DragonLauncher-主题库版.zip`，45.7 MB）
- 版本谱系：v0.1 原版 → v0.3 双主题版 → v0.4 主题库版

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 站点首页（纯静态，无构建步骤） |
| `assets/` | 样式、脚本、截图、主题缩略图与背景图 |
| `downloads/` | 四个版本的分发 zip 与 `SHA256SUMS.txt` |
| `packages/` | 社区作品与更新包 |

## 校验

下载后请对照 `downloads/SHA256SUMS.txt` 核对 SHA256，四个包逐行对应。

## 说明

- 启动器为朋友自制、社区维护，与 Mojang Studios / Microsoft 无关联；Minecraft 是 Mojang 的商标。
- 站点由 GitHub Pages 从 `main` 分支根目录直接发布，改 `index.html` 提交即生效。
- 主题包格式见站点「主题库」章节：zip 内含 `theme.json` + 壁纸 + `light.css` / `dark.css`。
